총 11개 작업

GitHub Actions에서 자동 실행되는 수집·집계 모듈입니다. Actions는 UTC로 동작하므로 실행 시각은 KST(UTC+9)로 변환해 표기했습니다. cron은 정각을 피해 잡았습니다. GitHub 문서가 매 시각 정각은 부하로 지연될 수 있다고 안내하기 때문입니다. 실제 실행이 예정보다 수십 분 늦을 수 있습니다.
