🔄 데이터 수집 로직

📥 Play-by-Play 데이터

출처: Naver 스포츠 문자중계

  • 투구별 상세 기록 (구종, 구속, 코스)
  • 타석 결과 (안타, 삼진, 볼넷 등)
  • 주루 상황 (주자, 득점)
  • PITCHf/x 트래킹 데이터

수집 주기: 시즌 종료 후 일괄 수집

📊 공식 통계 데이터

출처: KBO 공식 홈페이지

  • 타자 통계 (타율, OPS, 홈런 등)
  • 투수 통계 (평균자책점, WHIP, 탈삼진 등)
  • 팀별 집계 통계

수집 주기: 매일 새벽 1:30 자동 수집 (AWS EC2)

💡 자동화 시스템

AWS EC2 서버에서 cron job을 통해 매일 자동으로 최신 데이터를 수집하고 이메일로 알림을 발송합니다.

🗄️ 데이터베이스 구조

주요 테이블

1. games - 경기 기본 정보

game_id, 날짜, 홈/원정팀, 점수, 구장 등

2. play_by_play - 플레이별 상세 기록

투구 정보, 타격 결과, 주루 상황, PITCHf/x 데이터

3. kbo_official_batter_stats - 타자 공식 통계

타율, OPS, 홈런, 타점, 도루 등

4. kbo_official_pitcher_stats - 투수 공식 통계

평균자책점, WHIP, 승패, 세이브 등
