# 네이버 시즌 기록 API 가 뺀 투수 10명(27행)

KBO 이용약관(2026-10-14 시행)으로 공식 기록을 네이버 값으로 바꾸면서(evan 결정 2),
지금 DB(10/14 전에 KBO 에서 받은 값)에는 있는데 네이버 시즌 기록 API 에는 없는 투수
행이 27행 나왔습니다. 원인을 숫자로 확인했습니다(2026-10-18).

## 확인한 것

1. **네이버 시즌 기록 API 에 없습니다.** 그 시즌 10개 팀 목록(팀별로 받음)을 ID 로도
   이름으로도 찾았지만 투수·타자 어느 목록에도 없습니다. 선수 상세
   (`/statistics/categories/kbo/seasons/{y}/players/{id}`)도 400 입니다.
2. **경기 기록에는 있습니다.** 네이버 박스스코어(`/schedule/games/{id}/record`)의 투수
   줄에 같은 ID 로 나옵니다(예: 20130402LTNC0 이민호, 20200531LTOB02020 문대원).
3. **PBP(네이버 문자중계)에도 있습니다.** 27행 가운데 24행은 등판 경기 수·상대 타자 수·
   삼진이 DB 와 똑같습니다. 다른 3행은 이민호 2017·2018 상대 타자 1명, 이종혁 2019 1경기
   (그 경기 PBP 가 빠짐)입니다.
4. **이름이 바뀐 선수가 섞여 있습니다.** PBP 이름은 박성웅 → 박주홍, 문원 → 문대원입니다.
   다만 나머지 8명은 이름이 같아서, 개명만으로는 설명이 안 됩니다. 네이버가 왜 뺐는지는
   응답만으로 알 수 없습니다.
