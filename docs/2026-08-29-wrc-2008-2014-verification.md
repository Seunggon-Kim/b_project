# 2008~2014 wRC+ 검증 기록 (2026-08-29)

Statiz 상위 20명과 여섯 시즌을 맞대 봤습니다.

## 대조할 때 주의할 점

**이름만으로 맞추면 안 됩니다.** 2010 김태완은 LG(162타석)와
한화(473타석) 둘입니다. 이름만 보고 엉뚱한 쪽을 비교해 표준편차가
9.36 으로 부풀었습니다. 팀까지 맞추니 5.36 이 됩니다. 2013 이병규도
같습니다.

## 편차의 구조

우리 wOBA 가 장타를 더 크게, 단타를 더 작게 봅니다. Statiz wOBA 와
리그 평균 초과분의 배율을 재면 0.61~1.40 으로 흩어집니다(표준편차
0.212). 배율이 일정하면 스케일 차이인데, 흩어지므로 계산이 다릅니다.

    배율 큰 쪽   최정 1.40(26홈런), 나지완 1.33, 강민호 1.32
    배율 작은 쪽  김선빈 0.61(5홈런), 박한이 0.76(1홈런), 이진영 0.76

뿌리는 단타 득점가치입니다. 홈런 순가치는 시즌마다 1.69~1.76 으로
같은데 단타만 옛 시즌에 낮습니다.

## 데이터 오류인지 확인한 것

RE24 에서 무사 1루 대비 무사 1·2루 비가 2011·2012 만 0.213 입니다
(다른 시즌 0.24~0.29). 출루율로 정규화해도 그 두 해만 앞뒤보다
낮습니다. 주자가 덜 잡히는가를 네 갈래로 확인했습니다.

**1. 중계 텍스트에 주자 행이 있는가** — 있습니다. 시즌당 20경기를
세니 타석당 비율이 2012(0.0590)가 2019(0.0577)보다 높습니다.

**2. 표현 형식이 다른가** — 같습니다. 2012 와 2024 모두 '2루까지
진루', '홈인', '3루까지 진루', '도루로 2루까지 진루', '포스아웃'
입니다. 건수도 비슷합니다(189 대 198).

**3. 실제 경기가 맞는가** — 맞습니다. 20120407HHLT0 1회말을 한 줄씩
보니 아웃카운트·주자·득점이 전부 정확합니다.

**4. 홈런 뒤 주자가 비워지는가** — 비워집니다. 홈런이 나오면 주자가
모두 들어오므로 다음 타석은 주자가 없어야 합니다.

| 시즌 | 홈런 | 다음 타석 주자 있음 | 비율 |
|---|---|---|---|
| 2011 | 744 | 0 | 0.00% |
| 2012 | 611 | 0 | 0.00% |
| 2019 | 999 | 0 | 0.00% |
| 2024 | 1,424 | 1 | 0.07% |

유일한 1건이 오히려 2024 입니다.

## 결론

파서의 주자 처리는 정상입니다. 2008~2014 에 데이터 오류가 있다는
가설은 기각합니다. 남은 편차는 두 사이트의 계산식 차이로 봅니다.
우리는 FanGraphs 식 wOBA 가중치를 쓰고 Statiz 는 자체 방식을 씁니다.

## 한때 잘못 짚었던 것

**'중계와 53.8% 불일치'** — 대조 오류였습니다. 중계는 `no` 역순으로
오는데 순서대로 짝지었습니다. 게다가 네이버는 옛 경기의
`currentGameState` 를 전부 0 으로 주므로 애초에 정답으로 쓸 수
없습니다.

**`statiz_yearly_constants` 캡처값** — 신뢰하기 어렵습니다. 그 값
기준으로는 2024 가 23% 벌어지고 2012 는 1.4% 만 벌어지는데, 실제
wRC+ 대조는 정반대입니다.

## 함께 고친 것

이 조사 중에 찾아 고친 실제 결함입니다.

- 파서가 중계 구멍에서 죽어 105경기가 잘려 있었습니다. 넘어가도록
  고쳐 60경기를 복구했습니다(D1 반영 완료).
- 2008~2014 wRC+ 918명 전원이 파크팩터 미보정이었습니다
  (`team_stadium_by_season` 이 2015년부터만 있었습니다).
- KIA 구장 이름이 연도와 무관하게 챔피언스 필드였습니다. 2013년까지는
  무등야구장입니다.
- 시즌 상수 L 을 지난 실행 결과에서 역산해 새 시즌을 만들 수
  없었습니다. PBP 직접 계산으로 바꿨습니다.
- wRC+ 범위가 2015~2026 에서 2008~2026 으로 넓어졌습니다.
